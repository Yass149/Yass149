## Selected work

- **[A/B testing: Cookie Cats](https://github.com/Yass149/ab-test-cookie-cats)** — Analysed an experiment with **90,189 players** from design to product decision. The proposed change reduced 7-day retention by **0.82 percentage points**; I flagged a sample-ratio mismatch and recommended **not shipping** it. Includes confidence intervals, multiplicity correction, simulations, and consistency checks.

- **[Privacy-preserving fraud detection](https://github.com/Yass149/privacy-preserving-fraud-detection)** — My MSc research tests GRU fraud detection with differential privacy on Elliptic and PaySim. A private-training setup missed every fraud case at its default threshold; oversampling restored **0.743 recall** on the Elliptic holdout, with a material privacy cost that I account for explicitly. [Try the results console](https://yass149.github.io/privacy-preserving-fraud-detection/).

- **[Industrial visual anomaly detection](https://github.com/Yass149/industrial-visual-anomaly)** — Built a normal-only, PatchCore-style detector with a FastAPI inspection interface. Image AUROC was **0.952–1.000** across three holdout categories, but calibrated decisions still missed defects. The repository shows both the ranking metrics and the actual errors.

- **[Carbon Window Agent](https://github.com/Yass149/carbon-window-agent)** — Built a local API and Streamlit app that schedules flexible electricity use from UK carbon forecasts. Tested Python functions calculate the numbers; tool traces expose what the assistant used, and a person approves every plan.

**Also:** [Phone2Panda](https://github.com/Yass149/phone2panda) turns phone-recorded routes into simulated robot motion and compares it with a straight-line controller ([watch the demo](https://github.com/user-attachments/assets/d6f34c27-e24b-484e-987e-88c90661ee87)); [Race Engineer AI](https://github.com/Yass149/f1-strategy) evaluates lap-time forecasts across 24 held-out F1 races (**1.344 s MAE** versus a **1.498 s** baseline).
