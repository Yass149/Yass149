## Evidence from my work

- **[A/B testing: Cookie Cats](https://github.com/Yass149/ab-test-cookie-cats)** — Analysed **90,189 players**. The proposed change reduced 7-day retention by **0.82 percentage points**; I flagged a sample-ratio mismatch and recommended **not shipping** it.
- **[Privacy-preserving fraud detection](https://github.com/Yass149/privacy-preserving-fraud-detection)** — My MSc research found that one DP-SGD setup missed every fraud case at its default threshold. Oversampling restored **0.743 recall** on the Elliptic holdout, with a privacy cost I report explicitly. [Explore the live results console](https://yass149.github.io/privacy-preserving-fraud-detection/).
- **[Industrial visual anomaly detection](https://github.com/Yass149/industrial-visual-anomaly)** — Built a normal-only detector with **0.952–1.000 image AUROC** across three holdout categories. Its calibrated threshold still missed defects; the repository shows the errors alongside the scores.
- **[Carbon Window Agent](https://github.com/Yass149/carbon-window-agent)** — Built a tested API and app for scheduling flexible electricity use from UK carbon forecasts. Python calculates the numbers, tool traces show the evidence, and a person approves every plan.
